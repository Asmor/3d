## About

The Boxtender extends the height of two-piece boxes to increase storage capacity. It consists of a bottomless rectangular frame. The frame has tabs on the bottom and top which provide a secure friction fit.

## Files

- [boxtender.FCStd](./boxtender.FCStd) - Parametric FreeCAD file for defining your own boxtenders
- [boxtender-fliptoons.stl](../../fliptoons/boxtender-fliptoons.stl) - Boxtender for Fliptoons

## Printing

Prints w/o supports. I printed in PETG, but should be fine in PLA.
