## About

A [boxtender](../generic/boxtender/README.md) to extend the Fliptoons box so you can store both seasons 1 and 2 in a single box.

## Files

- [boxtender-fliptoons.stl](./boxtender-fliptoons.stl) - Ready-to-print STL

## Printing

Prints w/o supports. I printed in PETG, but should be fine in PLA.
